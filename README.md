## 📌 Project Overview

Rockfalls are a major safety concern in open-pit mining environments. Sudden slope failures can cause damage to equipment, production losses, and serious risks to workers.

This project presents an AI-based real-time rockfall prediction and early-warning system that uses multi-source sensor data such as vibration, tilt, crack width, rainfall, and temperature.

An LSTM (Long Short-Term Memory) deep learning model is used to learn patterns from sensor data and predict potential rockfall conditions.

The system provides an interactive Streamlit dashboard for monitoring sensor values, analyzing prediction results, and viewing system metrics.

---

## 🎯 Objectives

- Predict potential rockfall events using sensor data.
- Analyze patterns in vibration, tilt, crack width, rainfall, and temperature.
- Use LSTM deep learning for time-series prediction.
- Provide a real-time monitoring interface.
- Display analysis and performance metrics.
- Provide an early-warning mechanism for potentially dangerous conditions.
- Allow sensor data to be exported for further analysis.
